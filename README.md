# Homework 6 — My First Compose App

## Task 3: Apa yang berubah dan apa yang sama antara 8 dp dan 48 dp
Oke jadi yang sama diantara 8 dp dan 48 dp adalah warna yang kugunakan yaitu Gray, teks juga gak berubah, gambar juga sama. Berdasarkan pengamatan saya yang berubah hanyalah jarak kosong antara bagian pinggir layar, di 8 dp isinya hampir nempel ke pinggir layar sedangkan pas 48 dp jadi masuk ke tengah layar isinya.
